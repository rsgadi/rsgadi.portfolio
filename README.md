# Rushil Gadi — Portfolio v2

A responsive, editorial-style personal portfolio built with plain HTML, CSS, and JavaScript. It includes clickable academic project reports, certificate previews, a filterable project gallery, and links to the Cafe Adda web app and MU Vocalyx YouTube channel.

## Preview locally
1. Unzip the package.
2. Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Before publishing
- Add your updated resume PDF and a visible resume link.
- Check every description and project role for accuracy, especially for group projects.
- The site currently links to your provided LinkedIn URL and GitHub username `rsgadi`; confirm both are the profiles you want public.
- The Cornell and NUS certificate gallery images use the supplied image files. If you have the original certificate PDFs, those can replace the image previews.
- Ensure you are comfortable making the reports and certificate files public before deploying.

## Publish with GitHub Pages
GitHub Pages hosts static HTML, CSS, JavaScript, and assets. Create or use a repository, upload the contents of this folder (so `index.html` is at the repository root), then in repository Settings → Pages choose the `main` branch and `/ (root)` as the publishing source. Wait for the deployment and use the URL shown in Settings → Pages.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
